# Provider Arrangements

A host commissioner will normally setup a tariff configuration to meet the needs of the contractual arrangements they have with their provider.

## Multiple Hosted Providers

Where a commissioner hosts multiple providers, they can all share the same tariff configuration as long as any differences in charges can be represented by a single factor - Provider A is on an MFF of 1.20 and Provider B is on an MFF of 1.17.

## A Provider With Multiple Host Commissioners

Occasionally a provider may be hosted by more than one commissioner; in which case the provider, may be working to very different contractual arrangements.  In these circumstances we can create multiple quasi-organisations for the provider, one associated with each host commissioner.  Each quasi-organisation is then listed as a participating provider to the appropriate tariff configuration for their host commissioner.  In these case we usually use the provider's name and add a suffix to indicate the local authority district associated with the commissioner concerned, such as 'Blackpool Teaching Hospitals NHS Foundation Trust (Blackpool)' indicating the Blackpool Teaching Hospitals NHS Foundation Trust clinics in Blackpool local authority district.
